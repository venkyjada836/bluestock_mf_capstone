# Bluestock Mutual Fund Analytics Capstone

## Project Overview

This project provides an end-to-end mutual fund analytics platform that performs data ingestion, ETL, exploratory data analysis, fund performance analytics, advanced risk assessment, and interactive dashboard visualization.

## Project Objectives

* Analyze mutual fund industry trends
* Study fund performance and risk metrics
* Understand investor behavior and SIP trends
* Build a fund recommendation engine
* Develop interactive dashboards

## Tech Stack

* Python

* NumPy

## How to Run

### Activate Environment

```bash
venv\Scripts\activate
```

### Run ETL Pipeline

```bash
python scripts\etl_pipeline.py
```

### Run Dataset Validation

```bash
python scripts\check_datasets.py
```

### Run Fund Recommender

```bash
python scripts\recommender.py
```
